LOAD TEST COMMANDS  (PowerShell, run from the project root)
=========================================================

Every command runs through run-and-archive.ps1, so results go to:
  reports/archive/<script>/<timestamp>/


HOW TO PICK A MODE
------------------
  FIXED COUNT     You decide the total number of requests.
                  Use for: write / money / SMS flows, anything you need to control exactly.
                  Key settings: VUS, ITERATIONS_PER_VU (or REPEAT for list-based scripts).
                  Example: 5 VUs x 2 iterations = 10 requests, then it stops.

  CONSTANT USERS  VUS users stay busy for DURATION. Total requests depend on how fast the API answers.
                  Use for: capacity / max throughput, steady-load checks.
                  Key settings: VUS, DURATION (default 30s). Do NOT pass ITERATIONS_PER_VU.
                  Scripts that support PROFILE can use PROFILE=soak instead (same result).


SETTINGS THAT APPLY ACROSS SCRIPTS
----------------------------------
  VUS=<n>              number of virtual users
  DURATION=<time>      how long constant-user runs last, e.g. 30s, 5m
  ITERATIONS_PER_VU=<n> requests per user (fixed count)
  SLEEP=<seconds>      pause between requests; default 0 (max speed). Only in scripts that have it.
  PROFILE=soak         constant users for DURATION (where supported)
  REPEAT=<n>           repeat each item in the input list n times (list-based self-care scripts)

Replace the "..." placeholders with real values before running.
